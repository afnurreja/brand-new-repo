# Afnur.exe — Personal Portfolio

A simple personal portfolio website built as part of my Beyond Sigma course.

The main challenge was to create the entire website using **HTML only**.

## About the Project

I decided to make the portfolio look like a simple terminal / computer interface instead of creating a traditional portfolio.

The idea is that the website represents my personal digital desktop.

Visitors can explore different sections such as:

* About Me
* Projects
* Skills
* Learning Journey
* Contact
* Terminal
* Hidden / Secret section

## Technologies

This project intentionally uses only:

* HTML5

No CSS was used.

No JavaScript was used.

No frameworks or libraries were used.

## HTML Features Used

Some of the HTML features used in this project are:

* Semantic HTML
* Headings
* Paragraphs
* Lists
* Tables
* Forms
* Links
* Anchor navigation
* `<details>`
* `<summary>`
* `<header>`
* `<nav>`
* `<main>`
* `<section>`
* `<footer>`
* `mailto:` links

## Design

The design is inspired by old-school terminals and command-line interfaces.

Instead of using colors, animations, or JavaScript, the design relies on:

* Tables
* Borders
* Text
* ASCII-style symbols
* HTML structure
* Expandable `<details>` sections

## Running the Project

No installation is required.

Simply open `index.html` in a web browser.

## Goal

The goal of this project was to see how creative a portfolio can be when working under a strict limitation of using HTML only.
